# Proyecto PC Virtual Linux 🖥️

¡Bienvenidos al **PC Virtual Linux**! Este proyecto está en pleno proceso de **rework** desde cero, con una **actualización completa** y muchas mejoras que transformarán la experiencia de usuario. Actualmente, el proyecto está en construcción, pero tenemos grandes planes para ello.

## ¿Qué es PC Virtual Linux? 🤔

**PC Virtual Linux** es una simulación de un entorno de sistema operativo Linux dentro de un juego retro, donde el jugador puede interactuar con una consola virtual. El objetivo es crear una experiencia inmersiva en la que los jugadores puedan ejecutar comandos, herramientas de hacking simuladas y realizar tareas propias de un entorno Linux.

### Características actuales y futuras 🌟:

- **Interfaz tipo consola retro**: Atractiva, sencilla y fiel a la estética de los sistemas operativos antiguos.
- **Comandos interactivos**: El jugador podrá ejecutar comandos como si estuviera utilizando una terminal real.
- **Simulación de herramientas de hacking**: Después de superar un minijuego de hacking, el jugador podrá interactuar con herramientas de hacking de manera simulada.
- **Sistema de ayuda completo**: Para que jugadores de cualquier nivel, desde principiantes hasta expertos, puedan disfrutar del juego.
- **Rework completo**: Todo el sistema está siendo renovado desde cero, con nuevas funcionalidades, una estructura mejorada y un rendimiento optimizado.

## Estado del Proyecto 🏗️

El proyecto está en **construcción** y en su fase de **rework completo**. Se están implementando nuevas características, mejoras de rendimiento y rediseños de la interfaz para ofrecer una experiencia más fluida y agradable.

### Plan de desarrollo 🚀

- **Rework completo del código base**: Renovación total de la arquitectura del proyecto.
- **Optimización de la experiencia de usuario**: Mejoras en la interfaz, interacción y comandos disponibles.
- **Nuevas funcionalidades**: Herramientas y minijuegos adicionales, incluyendo opciones de personalización.
- **Compatibilidad y accesibilidad**: El juego se diseñará para todos los niveles de habilidad, con opciones de ayuda y tutoriales interactivos.
